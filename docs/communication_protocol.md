# 串口通信协议文档（物理串口）

## 1. 概述

本文档定义 Linux 侧与 RT-Thread 侧之间的物理串口通信协议。

- **物理接口**：UART7（40Pin 引脚 11（RTT RX）、15（RTT TX）、GND）
- **波特率**：1500000
- **数据位**：8
- **停止位**：1
- **校验位**：无
- **数据流向**：全双工

## 2. 帧格式

每一帧数据采用以下格式：

| 字段 | 字节数 | 说明 |
|------|--------|------|
| 帧头 | 1 | 固定 `0xAA`，表示一帧开始 |
| 数据长度 | 1 | 数据字段的字节数（不包含帧头、长度、校验） |
| 指令类型 | 1 | 表示本条指令的功能（见下表） |
| 数据 | 0~8 | 具体数据内容 |
| 校验和 | 1 | 从帧头到数据字段所有字节的异或值 |

**帧结构示例**：
[0xAA] [0x06] [0x01] [0xF4 0x01 0x00 0x00 0x00 0x00] [校验]
头 长度 类型 速度指令 (vx=500) 校验


## 3. 指令类型定义

| 指令码 | 方向 | 名称 | 说明 |
|--------|------|------|------|
| 0x01 | Linux → RT-Thread | 速度控制 | 发送 vx, vy, omega (mm/s, 0.01rad/s) |
| 0x02 | Linux → RT-Thread | 急停 | 立即停止运动 |
| 0x03 | RT-Thread → Linux | 里程计反馈 | 回传当前位姿 (x, y, theta) |

## 4. 各指令详细定义

### 4.1 速度控制（0x01）

**方向**：Linux → RT-Thread

**数据字段**（6 字节，int16 小端）：

| 字节偏移 | 内容 | 单位 | 范围 |
|----------|------|------|------|
| 0-1 | vx | mm/s | -1000 ~ 1000 |
| 2-3 | vy | mm/s | -1000 ~ 1000 |
| 4-5 | omega | 0.01 rad/s | -500 ~ 500 |

**示例**：前进 500 mm/s
[0xAA][0x06][0x01][0xF4 0x01 0x00 0x00 0x00 0x00][校验]


### 4.2 急停（0x02）

**方向**：Linux → RT-Thread

**数据字段**：无（长度=0）

**示例**：
[0xAA][0x00][0x02][校验]


### 4.3 里程计反馈（0x03）

**方向**：RT-Thread → Linux

**数据字段**（12 字节，int32 小端）：

| 字节偏移 | 内容 | 单位 |
|----------|------|------|
| 0-3 | x | mm |
| 4-7 | y | mm |
| 8-11 | theta | 0.01 rad |

**示例**：位置 (1000mm, 500mm)，朝向 1.57 rad
[0xAA][0x0C][0x03][0xE8 0x03 0x00 0x00 0xF4 0x01 0x00 0x00 0x64 0x00 0x00 0x00][校验]


## 5. 校验和计算

校验和 = 帧头 ⊕ 数据长度 ⊕ 指令类型 ⊕ 数据字节1 ⊕ ... ⊕ 数据字节N

**Python 示例**：
```python
def calc_checksum(data: bytes) -> int:
    checksum = 0
    for b in data:
        checksum ^= b
    return checksum
```
## 6. 通信流程
Linux 侧每 20~50ms 发送一次速度控制帧。

RT-Thread 侧每 20ms 回传里程计反馈帧。

若 Linux 连续 100ms 未收到反馈，则发送急停。

## 7. 错误处理
校验失败：丢弃该帧，等待下一帧。

超时：RT-Thread 自动减速至停止。

未知指令码：忽略。
